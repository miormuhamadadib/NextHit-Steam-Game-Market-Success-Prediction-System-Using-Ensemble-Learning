ABOUT THE PROJECT

Predicting Success
Before Launch.

With thousands of games launching annually on Steam and 71% of titles falling into low-success categories, indie developers need more than intuition.

NextHit analyzes pre-launch metadata — price, genres, tags, and release timing — using a weighted XGBoost ensemble model optimized with SMOTETomek to handle severe class imbalance.
